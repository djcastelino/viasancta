# Sacred journeys design preview

The homepage identity now continues through Eucharistic Miracles, Marian Apparitions, Sacred Mountains, Sacred Architecture, Stations of the Cross, Biblical Timeline and Jesus in the Old Testament. Shared photographic introductions, ivory/plum/gold materials, a collection navigation strip and consistent footers connect the routes. Matching discovery cards lead into redesigned detail panels; miracle detail pages receive the same materials and photographic heading.

Existing data, search/filter behaviour, daily church/Scripture selection, station controls, timeline periods and reflection handlers remain connected. Modal panels support Escape, keyboard focus containment and focus restoration. Eucharistic and Marian collection music is now an explicit optional control rather than automatic page-entry playback. Stations retains its immersive prayer mode.

This extends the Scripture tools preview on the same branch. Production is unchanged. Validation includes a production build and ten existing backend, game-progress and playback-lifecycle tests, plus browser checks across all seven routes, collection search, miracle detail, Marian/mountain/church/timeline panels, station navigation and phone layouts. Visual checks remain silent; no narration playback was exercised in this design pass.
